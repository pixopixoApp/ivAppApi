# DiceBear social seed avatar licenses

- Generator API version: `10.x`
- Styles: `cameo`, `clay`, `cutouts`, `gaze`, `initial-face`, `landscape`,
  `line-face`, `lorelei`, `moods`, `notionists`, `open-peeps`, `pixel-art`
- License: CC0 1.0 for every listed style
- Official license list: https://github.com/dicebear/styles/blob/main/LICENSE.md

The initialization manifest records the selected style, generator version,
seed, OSS key, and SHA-256 digest for every avatar. Avatars are copied into
Pixo OSS; public clients never depend on the DiceBear API at runtime.
